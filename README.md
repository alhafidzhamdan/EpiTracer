# EpiTracer

<!-- badges: start -->
<!-- badges: end -->

> **EpiTracer** — *calling and visualising extrachromosomal circular DNA
> amplicons likely generated from simple excision events.*

EpiTracer provides **two independent tools** for whole-genome sequencing (WGS)
data — click a tool for its full documentation:

| Tool | Purpose |
| :--- | :--- |
| [**`call_episomal_ecdna()`**](docs/call_episomal_ecdna.md) | An episomal ecDNA caller — flags ecDNA amplicons likely generated by simple episomal exclusion. |
| [**`plot_sv_linear()`**](docs/plot_sv_linear.md) | A general-purpose, flexible plotter for structural variants and copy number. |

> [!IMPORTANT]
> `call_episomal_ecdna()` relies on the focal amplicon calls from
> [AmpliconArchitect](https://github.com/AmpliconSuite/AmpliconArchitect). In
> addition, it is recommended that copy-number variant (CNV) and structural
> variant (SV) inputs are generated by
> [PURPLE](https://github.com/hartwigmedical/hmftools/tree/master/purple), part
> of the Hartwig Medical Foundation (HMF) pipeline. This is because the tools
> rely on accurate copy-number segmented SV calls which are critical in
> nominating amplicons formed via simple episomal exclusion events. Should they
> choose however, users may opt to coerce the appropriate required metadata
> derived from other SV and CNV callers, although this is not the recommended
> option.

## Installation

Install with `BiocManager`, which resolves the Bioconductor
(`GenomicRanges`, `regioneR`), GitHub ([`gUtils`](https://github.com/mskilab/gUtils))
and `Remotes:` dependencies in one call:

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")
BiocManager::install("alhafidzhamdan/EpiTracer")
```
