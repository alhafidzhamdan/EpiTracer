# `call_simple_excision()` — An episomal ecDNA caller

> Formerly `call_episomal_ecdna()`. **Episomal ecDNA** is defined *strictly* as
> ecDNA formed by **simple excision** — a circle bounded by a duplication
> junction — as opposed to inverted-duplication or complex, breakage-driven
> amplicons.

A tool to **call extrachromosomal circular DNA (ecDNA) amplicons likely
generated by simple excision**. For each amplicon it inspects the structural
variant breakpoints at the amplicon boundaries and flags those whose structure
fits the *episome* model of formation: a circular amplicon bounded by a
duplication (DUP) breakpoint, excised from an otherwise non-amplified
chromosomal region, often leaving a deletion **"excision scar"** at the origin
locus. Amplicons can be supplied from
[AmpliconArchitect](https://github.com/AmpliconSuite/AmpliconArchitect), or
detected from copy number alone (see *Input data*).

## How it works — the episome heuristic

For each amplicon, `call_simple_excision()`:

1. finds **DUP breakpoints at the amplicon boundaries** that are themselves
   amplified (`PURPLE_CN > 3 × ploidy`);
2. requires the boundary DUP to carry the **highest variant fraction (VF)** of
   any DUP in the amplicon;
3. requires the chromosomal segments immediately **flanking both boundaries to
   be non-gained** (consistent with a circle excised from a diploid region);
4. flags a shared flanking **deletion** as a candidate **excision scar**.

The founder must be a **copy-gaining** junction: an internal **inversion** that
out-copies the boundary DUP is the *inverted-duplication* signature and is **not**
episomal, whereas an internal **deletion** is an ancestral event and does not
disqualify the call. To nominate the founder circularisation junction explicitly
— via VF-stratified reconstruction — see
[`call_founder_boundary()`](https://alhafidzhamdan.github.io/EpiTracer/reference/call_founder_boundary.html).

## Input data

The SV and copy-number inputs are **required**; the AmpliconArchitect amplicon
regions (`ecdna_gr`) are **optional** — pass `ecdna_gr = NULL` and the focal
amplicons are detected from copy number alone via `detect_amplicon_seeds()`.
Each input is a `GRanges` with these metadata columns:

| Object (source) | Required metadata columns |
| :--- | :--- |
| `ecdna_gr` (AmpliconArchitect) | `ID`, `WGS_ID` |
| `breakpoints_gr` (PURPLE) | `WGS_ID`, `event`, `svclass`, `PURPLE_AF`, `PURPLE_JCN`, `VF`, `PURPLE_CN`, `insLen`, `HOMLEN` |
| `cnv_gr` (PURPLE) | `sample`, `copyNumber`, `ploidy`, `majorAlleleCopyNumber`, `minorAlleleCopyNumber` |
| `cancer_genes_gr` | `gene` (gene symbol; annotates overlapping breakpoints with the oncogene) |

## Arguments

**Required**

| Argument | Description |
| :--- | :--- |
| `breakpoints_gr`  | **PURPLE** SV breakpoints (GRanges); see *Input data*. |
| `cnv_gr`          | **PURPLE** allele-specific CN segments (GRanges). |
| `cancer_genes_gr` | Cancer-gene loci (GRanges) with a `gene` column; annotates breakpoints with the overlapping oncogene. |

**Optional — amplicon source**

| Argument | Default | Description |
| :--- | :--- | :--- |
| `ecdna_gr` | — | ecDNA amplicon regions from **AmpliconArchitect** (GRanges); needs `ID`, `WGS_ID`. Pass `NULL` to detect focal-amplicon seeds from copy number alone. |

**Optional**

| Argument | Default | Description |
| :--- | :--- | :--- |
| `ext`      | `1e7`   | bp to extend each amplicon by when searching for boundary SVs. |
| `mc.cores` | `1`     | Cores for parallel processing across amplicons. |
| `verbose`  | `FALSE` | Print per-amplicon progress. |

Returns a `data.table` of annotated breakpoints with per-amplicon episomal
classifications (`episomal`, `has_excision_scar`, …).

## Example

```r
library(EpiTracer)

episomal <- call_simple_excision(
  ecdna_gr        = ecdna_gr,        # AmpliconArchitect amplicon regions; $ID, $WGS_ID (or NULL)
  breakpoints_gr  = breakpoints_gr,  # PURPLE SV breakpoints
  cnv_gr          = cnv_gr,          # PURPLE allele-specific CN segments
  cancer_genes_gr = cancer_genes_gr, # cancer-gene loci (needs a `gene` column)
  ext             = 1e7,
  mc.cores        = 4
)
```
