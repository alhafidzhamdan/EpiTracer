# Example inputs for `call_simple_excision()`

A small, self-contained toy dataset describing a textbook **episomal
EGFR ecDNA** on chr7 in a fictional sample `"EXAMPLE01"`: a focal
amplification bounded by a high variant-fraction duplication (the
circularisation junction), excised from otherwise diploid flanks and
leaving a low-VF deletion "excision scar". The data are synthetic (no
patient data) so the example runs anywhere in seconds and
[`call_simple_excision()`](https://alhafidzhamdan.github.io/EpiTracer/reference/call_simple_excision.md)
flags the amplicon as episomal.

## Usage

``` r
ex_caller_inputs
```

## Format

A named `list` of four
[GenomicRanges::GRanges](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
objects, matching the four required arguments of
[`call_simple_excision()`](https://alhafidzhamdan.github.io/EpiTracer/reference/call_simple_excision.md):

- `ecdna_gr`:

  AmpliconArchitect-style ecDNA amplicon region; metadata `ID`,
  `WGS_ID`.

- `breakpoints_gr`:

  PURPLE-style SV breakpoints; metadata `WGS_ID`, `event`, `svclass`,
  `PURPLE_AF`, `PURPLE_JCN`, `VF`, `PURPLE_CN`, `insLen`, `HOMLEN`.

- `cnv_gr`:

  PURPLE-style allele-specific copy-number segments; metadata `sample`,
  `copyNumber`, `ploidy`, `majorAlleleCopyNumber`,
  `minorAlleleCopyNumber`.

- `cancer_genes_gr`:

  Cancer-gene loci (EGFR) with a `gene` column.

## Source

Synthetic; generated by `data-raw/make_example_data.R`.

## See also

[`call_simple_excision()`](https://alhafidzhamdan.github.io/EpiTracer/reference/call_simple_excision.md),
[ex_plot_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_plot_inputs.md)

## Examples

``` r
res <- call_simple_excision(
  ex_caller_inputs$ecdna_gr, ex_caller_inputs$breakpoints_gr,
  ex_caller_inputs$cnv_gr,   ex_caller_inputs$cancer_genes_gr
)
res$episomal
#> [1] "TRUE" "TRUE" "TRUE" "TRUE"
```
