# Example inputs for `plot_sv_linear()`

The same episomal EGFR ecDNA as
[ex_caller_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_caller_inputs.md),
expressed in the data-frame format expected by
[`plot_sv_linear()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_linear.md)
for sample `"EXAMPLE01"`. `karyotype` and `gene_coord` are omitted so
the plotter falls back to the bundled hg38 references.

## Usage

``` r
ex_plot_inputs
```

## Format

A named `list` of three `data.frame`s:

- `cnv_data`:

  Copy-number segments; columns `sample`, `seqnames`, `start`, `end`,
  `copyNumber`, `ploidy`, `majorAlleleCopyNumber`,
  `minorAlleleCopyNumber`.

- `sv_data`:

  Structural variants; columns `chrom1`, `start1`, `chrom2`, `start2`,
  `strand1`, `strand2`, `svclass`, `VF`, `JCN`, `sample`.

- `wgd_data`:

  Whole-genome-duplication status; columns `sample`, `Polyploidy`.

## Source

Synthetic; generated by `data-raw/make_example_data.R`.

## See also

[`plot_sv_linear()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_linear.md),
[ex_caller_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_caller_inputs.md)

## Examples

``` r
p <- plot_sv_linear(
  sample   = "EXAMPLE01",
  cnv_data = ex_plot_inputs$cnv_data,
  sv_data  = ex_plot_inputs$sv_data,
  wgd_data = ex_plot_inputs$wgd_data,
  chromosome = "chr7"
)
```
