# Example inputs for `plot_sv_reconstruction()`: a complex CDK4 amplicon

A synthetic but realistic complex focal amplification – a heavily
rearranged **CDK4** amplicon on chr12 (sample `"EXAMPLE02"`) whose
statistics are modelled on a real ecDNA amplicon: ~250 intra-chromosomal
junctions (DEL/DUP/inversions) spanning read support from `VF` ~4 up to
a `VF`-496 founder, over an oscillating copy-number profile (CN 15-35).
So
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
rebuilds it wave by wave from the founder down. `karyotype` /
`gene_coord` fall back to the bundled hg38 references (CDK4 is
labelled).

## Usage

``` r
ex_recon_inputs
```

## Format

A named `list` of three `data.frame`s – `cnv_data`, `sv_data`,
`wgd_data` – matching the columns
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
expects (chr12, ~57.4-59.6 Mb around CDK4).

## Source

Synthetic; generated by `data-raw/make_example_data.R` (statistics
modelled on a real complex CDK4 amplicon, but all coordinates
simulated).

## See also

[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md),
[ex_plot_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_plot_inputs.md)

## Examples

``` r
p <- plot_sv_reconstruction(
  sample   = "EXAMPLE02",
  cnv_data = ex_recon_inputs$cnv_data,
  sv_data  = ex_recon_inputs$sv_data,
  wgd_data = ex_recon_inputs$wgd_data,
  chromosome = "chr12", chromosome_range = matrix(c(57e6, 60e6), nrow = 1),
  min_vf = 10
)
```
