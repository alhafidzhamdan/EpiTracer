# Example inputs for `plot_sv_reconstruction()`

A synthetic EGFR amplicon (sample `"EXAMPLE01"`, chr7) carrying many
duplication junctions across a wide read-support (`VF`) range, so
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
can rebuild it wave by wave — a high-`VF` founder, then successively
lower-`VF` waves. `karyotype`/`gene_coord` fall back to the bundled hg38
references.

## Usage

``` r
ex_recon_inputs
```

## Format

A named `list` of three `data.frame`s — `cnv_data`, `sv_data`,
`wgd_data` — matching the columns
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
expects.

## Source

Synthetic; generated by `data-raw/make_example_data.R`.

## See also

[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md),
[ex_plot_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_plot_inputs.md)

## Examples

``` r
p <- plot_sv_reconstruction(
  sample   = "EXAMPLE01",
  cnv_data = ex_recon_inputs$cnv_data,
  sv_data  = ex_recon_inputs$sv_data,
  wgd_data = ex_recon_inputs$wgd_data,
  chromosome = "chr7"
)
```
