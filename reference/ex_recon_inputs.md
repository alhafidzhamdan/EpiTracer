# Example inputs for `plot_sv_reconstruction()`: the DO11501T1 CDK4 amplicon

A real, complex focal amplification – the **CDK4** amplicon on chr12 in
tumour sample `"DO11501T1"` – carrying hundreds of structural-variant
junctions across a wide read-support (`VF`) range, so
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
can rebuild it wave by wave from the highest-`VF` founder down.
`karyotype` / `gene_coord` fall back to the bundled hg38 references
(CDK4 is labelled).

## Usage

``` r
ex_recon_inputs
```

## Format

A named `list` of three `data.frame`s – `cnv_data`, `sv_data`,
`wgd_data` – matching the columns
[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
expects (chr12, ~56-61 Mb around CDK4).

## Source

Copy-number segments and SV junctions for sample DO11501T1, subset to
the chr12 CDK4 region; generated by `data-raw/make_example_data.R`.

## See also

[`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md),
[ex_plot_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_plot_inputs.md)

## Examples

``` r
p <- plot_sv_reconstruction(
  sample   = "DO11501T1",
  cnv_data = ex_recon_inputs$cnv_data,
  sv_data  = ex_recon_inputs$sv_data,
  wgd_data = ex_recon_inputs$wgd_data,
  chromosome = "chr12", chromosome_range = matrix(c(57e6, 60e6), nrow = 1),
  min_vf = 10
)
```
