# Example small mutations with a kataegis cluster

Synthetic SNVs for sample `"EXAMPLE01"` on chr7, in the format
[`plot_sv_linear()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_linear.md)
expects for its optional `snv_data` panel: a localised **kataegis**
shower of APOBEC-like C\>N substitutions over the EGFR amplicon (short
intermutation distances) plus a few scattered background SNVs. Passed to
`plot_sv_linear(snv_data = ex_snv)` it adds a rainfall panel in which
the kataegis cluster dips toward the bottom.

## Usage

``` r
ex_snv
```

## Format

A `data.frame` with columns `sampleID`, `seqnames`, `start`,
`allelic_freq`, `variant_cn`, `type`, `ref`, `mut`.

## Source

Synthetic; generated by `data-raw/make_example_data.R`.

## See also

[`plot_sv_linear()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_linear.md),
[ex_plot_inputs](https://alhafidzhamdan.github.io/EpiTracer/reference/ex_plot_inputs.md)

## Examples

``` r
p <- plot_sv_linear(
  sample   = "EXAMPLE01",
  cnv_data = ex_plot_inputs$cnv_data,
  sv_data  = ex_plot_inputs$sv_data,
  chromosome = "chr7", chromosome_range = matrix(c(54e6, 56e6), nrow = 1),
  snv_data = ex_snv
)
```
