# Package index

## Detection

Call ecDNA amplicons that arose by simple episomal excision.

- [`call_episomal_ecdna()`](https://alhafidzhamdan.github.io/EpiTracer/reference/call_episomal_ecdna.md)
  : Call episomal extrachromosomal DNA from WGS structural variants
- [`detect_amplicon_seeds()`](https://alhafidzhamdan.github.io/EpiTracer/reference/detect_amplicon_seeds.md)
  : Detect focal-amplicon seeds from copy number alone

## Visualisation

Plot the structural rearrangements underlying focal amplifications.

- [`plot_sv_linear()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_linear.md)
  : Linear copy-number and structural rearrangement plot
- [`plot_sv_reconstruction()`](https://alhafidzhamdan.github.io/EpiTracer/reference/plot_sv_reconstruction.md)
  : Temporally-stratified rearrangement plot (SV+CN grouped by read
  support)
